# Планер

Личный планер, который вы разворачиваете себе сами за 15–20 минут. Бесплатно, без рекламы и без чужих серверов: сайт работает на GitHub Pages, а ваши записи лежат в вашем собственном закрытом репозитории на GitHub.

**Что умеет**

- Календарь с делами, временем и напоминаниями.
- Сроки сдачи («сдать до пятницы»): планер показывает, сколько дней осталось, и отдельно напоминает о сроке.
- Повторяющиеся дела: каждый день, по будням, по выбранным дням недели, раз в две недели, каждый месяц, каждый год.
- Дела без времени можно перетаскивать, чтобы выстроить порядок на день.
- Идеи — карточками, их можно перенести в план или развернуть в заметку.
- Заметки с форматированием: шрифты, цвет, выделение, заголовки, ссылки, списки и чек-листы.
- Документы: PDF, Word, Excel, фото и любые файлы до 25 МБ. Их можно прикреплять к делам и заметкам.
- Голосовой ввод: наговорите несколько дел подряд, и планер сам разложит их по дням, разделам, идеям и заметкам.
- Разделы с вашими названиями и цветами (до 8), фильтр по разделам.
- Шесть тем оформления: Авто, Мята, Сад, Море, Лаванда, Ночь.
- Синхронизация между телефоном и компьютером.
- Работает как приложение: значок на экране телефона, работает без интернета, присылает уведомления.
- Напоминания и утренняя сводка в Telegram, даже когда планер закрыт (по желанию).
- Виджеты: окно «поверх всех окон» на Windows, виджет на экран iPhone, закреплённая сводка в Telegram для Android.

**Что понадобится**

- Аккаунт на [github.com](https://github.com) (бесплатный). Если его нет, зарегистрируйтесь: это займёт пару минут.
- Компьютер для первой настройки. Дальше планером можно пользоваться и с телефона.
- Telegram — только если хотите напоминания туда.

## Шаг 1. Своя копия планера

1. Войдите в свой аккаунт на GitHub.
2. На странице этого репозитория нажмите зелёную кнопку **Use this template** → **Create a new repository**.
3. Заполните:
   - **Repository name**: `planer` (можно другое, но тогда адрес сайта будет другим);
   - видимость **Public**. Это обязательно: на бесплатном тарифе сайт работает только из открытого репозитория. Ваших записей здесь не будет, только код страницы.
4. Нажмите **Create repository**.

> Если кнопки **Use this template** нет, скачайте файлы (зелёная кнопка **Code** → **Download ZIP**), создайте у себя новый открытый репозиторий `planer` и загрузите в него все файлы через **Add file → Upload files**.

## Шаг 2. Включите сайт

1. В своём репозитории `planer` откройте **Settings** (шестерёнка вверху).
2. Слева выберите **Pages**.
3. В разделе **Build and deployment**: Source — **Deploy from a branch**, Branch — **main**, папка **/ (root)** → **Save**.
4. Подождите 1–3 минуты и обновите страницу. Вверху появится адрес вида **https://ваш-логин.github.io/planer/**. Это ваш планер, сохраните ссылку.

Планер уже открывается и работает, но пока хранит записи только в этом браузере. Чтобы записи были на всех устройствах, сделайте шаги 3–5.

## Шаг 3. Создайте хранилище для записей

Записи хранятся в отдельном **закрытом** репозитории, который видите только вы.

1. На GitHub нажмите **+** вверху справа → **New repository**.
2. **Repository name**: `planer-data`.
3. Видимость **Private** — обязательно.
4. Поставьте галочку **Add a README file**.
5. **Create repository**.

## Шаг 4. Создайте токен доступа

Токен — это ключ, по которому планер сохраняет записи в `planer-data`. У него будет доступ только к этому репозиторию.

1. Откройте [github.com/settings/personal-access-tokens/new](https://github.com/settings/personal-access-tokens/new) (или: аватар → **Settings** → **Developer settings** → **Personal access tokens** → **Fine-grained tokens** → **Generate new token**).
2. **Token name**: `planer`.
3. **Expiration**: самый долгий срок или **No expiration**. Когда срок выйдет, планер перестанет синхронизироваться, и токен придётся создать заново.
4. **Repository access** → **Only select repositories** → выберите **planer-data**.
5. **Permissions** → **Repository permissions** → **Contents** → **Read and write**.
6. Внизу **Generate token** и скопируйте токен (начинается с `github_pat_`). GitHub покажет его только один раз.

> Не публикуйте токен и не показывайте его на скриншотах. Если он куда-то утёк, удалите его на той же странице и создайте новый.

## Шаг 5. Подключите планер к хранилищу

1. Откройте свой планер (адрес из шага 2).
2. Вкладка **Настройки** → блок **Синхронизация через GitHub**.
3. В первом поле: `ваш-логин/planer-data`. Во втором: токен.
4. **Подключить**. Под названием планера появится зелёная точка и «синхронизировано через GitHub».

Сделайте это **на каждом устройстве** (телефон, рабочий компьютер, домашний) с тем же токеном. Изменения приходят на другие устройства в течение минуты и сразу, когда вы возвращаетесь в планер.

## Шаг 6. Установите планер на телефон и компьютер

Так у планера будет свой значок, он будет открываться без адресной строки и работать без интернета.

- **Android (Chrome):** откройте планер → меню ⋮ → **Установить приложение** (или «Добавить на главный экран»).
- **iPhone (Safari):** откройте планер → кнопка **Поделиться** → **На экран «Домой»**.
- **Windows (Chrome или Edge):** значок установки справа в адресной строке или меню → **Установить приложение «Планер»**.

Долгое нажатие на значок установленного планера открывает быстрые переходы: «Сегодня», «Идеи», «Заметки», «Документы».

## Шаг 7. Настройте под себя

Вкладка **Настройки** → **Оформление и разделы**:

- **Название планера** — то, что написано крупно вверху (например, «Планер Ани»).
- **Тема оформления** — запоминается на каждом устройстве отдельно. «Авто» сама переключается на тёмную тему вместе с телефоном или компьютером.
- **Разделы** — по умолчанию «Личное», «Работа», «Дом». Переименуйте их, добавьте свои (до 8), смените цвет нажатием на цветной квадрат. Если удалить раздел, его записи перейдут в первый раздел списка.

Название и разделы синхронизируются между устройствами вместе с записями.

Там же в **Напоминаниях** нажмите **Включить уведомления** и разрешите их в браузере. Тогда планер будет показывать системные уведомления, пока он открыт, даже свёрнутый.

## Напоминания в Telegram (по желанию)

Приходят, даже когда планер закрыт. GitHub каждые 5 минут проверяет ваши дела и пишет вам через бота: о делах, о сроках сдачи, а утром присылает план на день и закрепляет его в чате.

**1. Создайте бота**

1. В Telegram откройте **@BotFather** → отправьте `/newbot` → придумайте имя и логин бота.
2. BotFather пришлёт **токен бота** (вида `123456789:AA…`). Скопируйте его.
3. Найдите своего нового бота поиском и нажмите **Start**. Без этого бот не сможет вам писать.

**2. Узнайте свой Id**

Откройте **@userinfobot** → **Start**. Он пришлёт сообщение со строкой **Id: 123456789**. Это число и нужно.

**3. Добавьте секреты в репозиторий `planer`**

**Settings** → **Secrets and variables** → **Actions** → **New repository secret**. Добавьте три секрета:

| Название | Что вставить |
|---|---|
| `PLANER_TOKEN` | тот же токен GitHub, что вы вводили в планере (шаг 4) |
| `TELEGRAM_BOT_TOKEN` | токен бота от BotFather |
| `TELEGRAM_CHAT_ID` | ваш Id из @userinfobot |

Секреты никто не видит, даже если репозиторий открытый: GitHub показывает только их названия.

**4. Включите расписание**

В репозитории лежит файл `telegram/remind.yml`, сейчас он выключен. Чтобы включить:

1. Откройте `telegram/remind.yml` → кнопка копирования (два квадратика справа над текстом).
2. **Add file** → **Create new file**.
3. В поле имени файла введите ровно: `.github/workflows/remind.yml`. Когда вы наберёте `/`, GitHub сам превратит части в папки.
4. Вставьте скопированный текст → **Commit changes**.

**5. Проверьте**

Вкладка **Actions** → слева **Напоминания в Telegram** → **Run workflow** → **Run workflow**. Через полминуты бот пришлёт: «Планер: напоминания в Telegram подключены».

Если GitHub спросит, разрешить ли workflows, нажмите **I understand my workflows, go ahead and enable them**.

**Настройки по желанию** (**Settings** → **Secrets and variables** → **Actions** → вкладка **Variables** → **New repository variable**):

| Переменная | Значение | Что делает |
|---|---|---|
| `DIGEST_TIME` | `07:30` или `off` | время утренней сводки (по умолчанию 08:00) или выключить её |
| `TZ_NAME` | например `Asia/Yekaterinburg` | ваш часовой пояс (по умолчанию Москва) |
| `DATA_REPO` | `логин/название` | если хранилище называется не `planer-data` |

**Что важно знать**

- GitHub иногда запускает проверку с опозданием на 5–15 минут. Для важных дел ставьте напоминание с запасом.
- Если в репозитории `planer` 60 дней ничего не менялось, GitHub приостановит расписание и пришлёт письмо. Включить обратно: вкладка **Actions** → **Enable workflow**.
- Журнал запусков в открытом репозитории виден всем, поэтому названия дел в него не пишутся, только количество.

## Виджеты

Вкладка **Настройки** → **Виджет на компьютере и телефоне**.

- **Windows.** Кнопка **Поверх всех окон** открывает маленькое окошко с делами, которое не прячется за другими программами (Chrome и Edge). Кнопка **Скачать ярлык** открывает виджет отдельным окном. Чтобы виджет запускался вместе с Windows: Win+R → `shell:startup` → Enter → перенесите ярлык в открывшуюся папку.
- **iPhone.** Установите бесплатное приложение **Scriptable**, нажмите в планере **Скопировать скрипт**, вставьте его в Scriptable и добавьте виджет Scriptable на главный экран. Подробные шаги — рядом с кнопкой в планере.
- **Android.** Сайты не могут ставить виджеты на Android, поэтому виджетом служит Telegram: каждое утро бот закрепляет план дня, а виджет Telegram с этим чатом показывает его на главном экране. Нужны напоминания в Telegram (см. выше).

Ещё можно экспортировать дела в обычный календарь телефона: **Настройки** → **Экспорт в календарь телефона (.ics)**.

## Как пользоваться

**Голосом.** Нажмите микрофон на клавиатуре телефона (на компьютере — Win+H) и говорите прямо в поле «Наговорите, что нужно». Потом **Разобрать**: появится список, где можно поправить каждую запись, и **Сохранить все**. Примеры:

- «завтра в 10 созвон с коллегами, в пятницу забрать посылку» — два дела в календаре;
- «каждый понедельник в 9 планёрка по работе» — повторяющееся дело в разделе «Работа»;
- «сдать отчёт до пятницы» — дело со сроком сдачи;
- «идея: разобрать шкаф на выходных» — в Идеи;
- «запиши в заметку про ремонт: купить краску и валик» — в Заметки;
- «чек-лист в поездку: паспорт, зарядка, наушники» — заметка с галочками.

Раздел определяется, если назвать его в фразе: «по работе», «для дома». Иначе запись попадает в выбранный сверху раздел или в первый раздел списка.

**Календарь.** Нажмите на дело, чтобы изменить его: время, раздел, напоминание, повтор, срок сдачи, заметку, прикрепить файл. Дела без времени перетаскивайте за ручку из шести точек слева. На компьютере ручку можно двигать стрелками ↑ ↓. Крестик у повторяющегося дела убирает только этот день, всю серию удаляют в окне дела.

**Заметки.** Панель над текстом: шрифт, размер, заголовки, жирный и курсив, цвет и выделение, списки, чек-лист, ссылка. Всё сохраняется само.

**Документы.** Перетащите файлы в поле или нажмите на него, чтобы выбрать. Файлы хранятся в вашем закрытом `planer-data`, в папке `files`. Картинки, PDF и текст открываются прямо в планере, остальное скачивается. Прикрепить файл к делу можно в окне дела, к заметке — кнопкой **Файл**.

**Перенос и резервная копия.** **Настройки** → **Перенос данных** → **Сохранить в файл (.json)**. Этот файл можно загрузить обратно в любой копии планера: записи объединятся.

## Безопасность: что видно другим

| Что | Кто видит |
|---|---|
| Репозиторий `planer` (код планера) | все: он открытый, но в нём нет ваших данных |
| Сайт планера | любой, кто знает адрес, но без вашего токена он увидит пустой планер |
| Репозиторий `planer-data` (дела, заметки, документы) | только вы |
| Секреты Telegram и токен в настройках репозитория | никто, даже вы видите только названия |
| Токен в браузере | только этот браузер на этом устройстве |

Если вы потеряли телефон или токен куда-то утёк: удалите токен на [github.com/settings/personal-access-tokens](https://github.com/settings/personal-access-tokens), создайте новый и введите его заново на своих устройствах (и в секрете `PLANER_TOKEN`, если подключён Telegram).

## Если что-то не работает

| Что видно | Что сделать |
|---|---|
| Сайт пишет 404 | Подождите 2–3 минуты после шага 2. Проверьте, что в **Settings → Pages** выбрана ветка **main** и папка **/ (root)**, а репозиторий открытый. |
| «Репозиторий не найден или у токена нет к нему доступа» | Проверьте название (`логин/planer-data`, без пробелов). В настройках токена должны быть выбраны **planer-data** и **Contents: Read and write**. |
| «Репозиторий публичный» | Вы ввели репозиторий с кодом. Нужен закрытый `planer-data`. |
| «Токен не подходит» | Скопируйте токен целиком или создайте новый (у старого мог закончиться срок). |
| Красный текст «нет связи с GitHub» | Нет интернета. Записи сохранены на устройстве и уйдут, когда связь появится. |
| Открывается старая версия | Обновите страницу с Ctrl+F5. На телефоне закройте установленный планер и откройте снова. |
| Не приходят напоминания в Telegram | **Actions** → последний запуск → шаг «Отправить напоминания»: там написано, что не так. Чаще всего не нажат Start у бота или неверен `TELEGRAM_CHAT_ID`. |
| Напоминания перестали приходить через пару месяцев | GitHub приостановил расписание: **Actions** → **Enable workflow**. Или истёк токен. |
| Не загружается документ | Файл больше 25 МБ или не подключена синхронизация через GitHub. |

## Как обновить планер

Когда в исходном репозитории выйдет новая версия:

1. Скачайте из него новые `index.html` и `sw.js` (откройте файл → кнопка **Download raw file**).
2. В своём репозитории `planer`: **Add file** → **Upload files** → перетащите оба файла → **Commit changes**.
3. Через 2–3 минуты обновите планер (Ctrl+F5).

Ваши записи, разделы и настройки при этом не меняются: они лежат в `planer-data` и в браузере.
